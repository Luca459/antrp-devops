# ANTRP DevSecOps Consulting

Professionelle Website für DevSecOps-Consulting – Kubernetes, CI/CD, Security, HashiCorp Vault und mehr.

## Struktur

```
index.html        # Hauptseite
css/style.css     # Styles (Dark Theme)
js/main.js        # Interaktivität
```

## Lokal öffnen

```bash
# Einfach im Browser öffnen
open index.html

# Oder mit einem lokalen Server
python3 -m http.server 8080
```

## Anpassen

- **Name/Branding**: `ANTRP` in `index.html` und `css/style.css` ersetzen
- **Kontakt**: E-Mail-Adresse in `index.html` (Abschnitt `#contact`) aktualisieren
- **Formular**: Backend-Integration (z. B. Netlify Forms, Formspree) in `js/main.js` eintragen
- **Impressum/Datenschutz**: Eigene Seiten erstellen und im Footer verlinken
